# pi-nvim

Pi extension for sessions launched by `pi.nvim`.

It asks Pi to wrap concise progress updates and final results in `<show>...</show>`. The Neovim helper reads those tags directly from Pi's RPC stream. It has no TTS or Loqui dependency.

The installed extension path is symlinked to this directory:

```text
~/.pi/agent/extensions/pi-nvim -> ~/dotfiles/pi-stuff/extensions/pi-nvim
```
