# BB Custom Sidebar

BB Custom Sidebar replaces the BB sidebar thread list with a recent threads section and a project list.

The sidebar includes:

- Running and recently updated threads at the top.
- Collapsible projects with numbered thread rows.
- Colored addition and deletion counts on dirty thread rows.
- A filter for projects with active or unread threads.
- A button for starting a thread in each project.
- Automatic project icons found or generated by a small hidden Pi worker.

Hover over any thread to see its latest message, exact colored Git counts, status, and age. Message previews are limited to 180 characters, and the card stays 320 pixels wide. The hover card shows Create PR when the working tree has uncommitted changes. Create PR asks the thread agent to review, commit, push, and open a pull request. A clean thread shows Archive instead.

## Install

```sh
npm install
bb plugin build
bb plugin install .
```

Select **BB Custom Sidebar** under **Settings > Appearance > Sidebar** if BB does not select it automatically. You can set the recent thread window on the plugin settings page.

Automatic project icons are generated lazily for visible projects and cached. The plugin prefers a hidden Pi worker using `openai-codex/gpt-5.4-mini`, then falls back to the project's default provider when Pi is unavailable. The worker first looks for a favicon or small app icon. If none exists, it reads the README and returns minimal black-and-white retro line art as a safe SVG. The provider behavior, Pi model, and generation style brief can be changed in plugin settings.

The plugin also gives project agents a `set_bb_project_icon` tool. Ask an agent to change or restyle the current BB project icon and it can install a safe 24 by 24 SVG immediately. Agent-set icons remain pinned instead of being replaced by automatic refreshes.
